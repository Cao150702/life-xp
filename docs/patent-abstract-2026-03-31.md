# 说明书摘要

**（泛化版——想法优先，为后续开发留空间）**

---

本实用新型公开了一种基于交叉对生叠层结构的仿生防撞吸能装置。

本装置的核心构思在于：将自然界中交叉对生排布方式的结构原理——即若干弧形盾片状片层构件以相邻叠层旋转预定角度的方式叠合排布——应用于冲击防护领域，通过片层之间的受控逐级屈曲、相邻层的受控相对滑移、以及中心空腔的渐进压缩变形，实现冲击能量的多级有序吸收。

所述片层构件的厚度可沿径向方向呈梯度变化，形成天然的梯度刚度特征。相邻片层之间预留有供其发生相对运动的间隙。若干片层围设形成闭合腔体结构，内部设有中心空腔。

本装置可在受到外部冲击载荷时依次经历三个吸能阶段：外层片层的逐级屈曲吸能、相邻层片层的层间滑移耗能，以及中心空腔的渐进压缩吸能，实现稳定可控的全程渐进式能量吸收。

可选地，片层可采用双层复合结构，利用吸湿材料的体积变化实现无源自适应调节，使装置的抗冲击性能随环境湿度自动调整，无需外部供能和控制元件。

本实用新型的保护范围以权利要求书记载的内容为准，适用于汽车防护、头盔缓冲、无人机抗冲击、轨道交通及其他涉及冲击防护的应用场景。（附图1幅）
